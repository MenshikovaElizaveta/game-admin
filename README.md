 # Система администрирования партий

Десктоп-приложение для администрирования партий в настольную игру экономического типа.

Не является игрой. Инструмент для ведущего, который позволяет:
- Вносить и валидировать ходы игроков по правилам
- Автоматически рассчитывать финансы, аренду, налоги
- Хранить историю партий и формировать статистику игроков
- Предоставлять удобный GUI для ввода данных
